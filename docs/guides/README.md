## Puerta de calidad
- El kit está implementado y protegido por entitlement exacto en backend.
- Fórmulas con especificación, pruebas unitarias y ejemplos reproducibles.
- Campos y unidades coinciden con la interfaz real.
- Capturas de la versión candidata.
- Ejemplos verificados contra fixtures versionados.
- Limitaciones, FAQ, fecha y versión del motor.
- Prueba de usuario principiante.
- Sin promesas de resultados ni asesoría contable, fiscal o legal.

Cada fórmula debe mostrar variables, unidad, periodo, fórmula, supuesto, ejemplo y exclusiones. No mezclar monedas o periodos. Revisar guía y pruebas junto con cada cambio del motor.
