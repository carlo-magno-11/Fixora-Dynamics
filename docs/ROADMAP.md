# Roadmap

1. Fundación: repo, arquitectura, documentación, motor base.
2. Motor: costes, mano de obra, merma, gastos, comisiones configurables, punto de equilibrio y pruebas límite.
3. Calculadora general: formularios, desglose, precio/margen/recargo, escenarios y accesibilidad.
4. Supabase: proyecto independiente, migraciones perfiles/negocios/membresías, Auth, RLS y aislamiento multiusuario.
5. Licencias: anual desde activación, tres dispositivos, revocación/renovación.
6. Administración/Etsy: MFA, pedidos, códigos y auditoría.
7. Libro, exportaciones PDF/CSV y PWA offline limitado.
8. Seguridad, E2E, staging, carga, recuperación y lanzamiento.

Especializaciones ropa/repostería/artesanía fuera del MVP.
